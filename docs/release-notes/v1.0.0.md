# tekken6-nx 1.0.0

The first release of **Tekken 6** (Xbox 360) as a native Nintendo Switch homebrew: the game's code statically
recompiled with ReXGlue and drawn on the Switch GPU with reNut's deko3d renderer.

> [!IMPORTANT]
> This release contains **no game data**. You need your own copy of the Xbox 360 disc: *Tekken 6 (Europe)
> (En,Ja,Fr,De,Es,It,Ko,Ru) (Rev 1)*, `default.xex` SHA-256
> `ee138a4fe8d32a0edc131451377f4377041a49626153fa992db24f5420a7f15c`.

## How to install

1. Open the installer page: **https://xsaja.github.io/tekken6-nx-installer/** (Chrome or Edge on a computer).
2. Choose your disc image (`.iso`) or the folder you extracted it into, and press **Create tekken6-nx.zip**. Everything
   runs in your browser; your files never leave your computer.
3. Extract the zip to the root of the SD card (it holds the `switch/tekken6-nx/` folder).
4. Make a forwarder with **[Sphaira](https://github.com/ITotalJustice/sphaira)** for
   `switch/tekken6-nx/tekken6-nx.nro`, with a **39-bit address space**, and always start the game from the forwarder's
   icon on the HOME menu.

> [!CAUTION]
> Started from the forwarder's icon, the game runs on **all four CPU cores**. Started from Sphaira's list, it gets three
> and runs clearly slower.

## What works

- Checked on a retail console at stock clocks, installed from the page's zip on a clean SD card: the menus, the
  character select and fights on several stages.
- 60 fps in menus and the lighter stages; the heaviest fights in the mid 50s.
- The game's own 1024x576 image, in handheld and docked.
- Shaders made from your own copy by the installer; the ones the console needs are compiled once and kept.
- Controls by position as on the Xbox 360 pad (or by letter), remappable for each player in `tekken6.toml`.

## Known issues

- **Character select with 2D portraits only:** a setting stored in some save files, not the port. The fix is in
  [docs/tekken6-notes.md](https://github.com/xsaja/tekken6-nx/blob/main/docs/tekken6-notes.md#character-select-in-2d).
- **The first session** stutters for a moment in new places while the console compiles the shaders it has not met yet.
- **Motion blur** is drawn only when the game thinks it has time to spare (`tekken_blur_always = true` forces it, at
  about 3 ms a frame).
