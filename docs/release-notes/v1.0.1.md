# tekken6-nx 1.0.1

## Fixed: the "gamer profile has changed" loop

If you played on a Switch Lite with an external controller, or on a Switch with the Joy-Cons attached and another
controller connected, you may have hit this: you press START on the title screen and the game says "The gamer
profile has changed. Returning to the title screen." Then it keeps doing it every time.

Here's what was going on. On the Xbox 360, every controller belongs to a player, and each player can be signed in
with their own profile. Our port only had one profile, for player 1. The console's own controls always connect
first, so they were player 1, and your external controller ended up as player 2, with no profile at all. Tekken 6
remembers which controller pressed START and keeps checking that its player is still signed in. It saw player 2
with nobody signed in, thought the profile had changed, and sent you back to the title screen. You'd press START
again with the same controller and go round in circles.

The fix is simple: now every controller plays with the same profile. Use whichever one you like to start the game.
